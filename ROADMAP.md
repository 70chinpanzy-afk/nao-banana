# Roadmap

This roadmap keeps the project direction visible for users, contributors, and reviewers.

## Near Term

- Add screenshots to README.
- Add a small smoke test suite.
- Add GitHub Actions CI for Python syntax and dependency checks.
- Add a model selection setting.
- Improve error messages for API key, quota, and safety-filter failures.
- Create the first GitHub release.

## Medium Term

- Add configurable output sizes when supported by the selected model.
- Add prompt history export.
- Add examples for education, social posts, product mockups, and blog thumbnails.
- Add safer deployment guidance for Streamlit Community Cloud or other hosts.
- Add Japanese and English README sections.

## Maintainer Workflow Goals

- Use issues for bugs and feature requests.
- Use pull requests for all non-trivial changes.
- Keep release notes in CHANGELOG.
- Review dependency and credential-handling changes carefully.
- Use Codex to assist PR review, issue triage, release checklists, and documentation maintenance.
